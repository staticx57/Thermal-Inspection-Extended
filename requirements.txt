# ============================================================================
# Platform-Specific Notes
# ============================================================================
#
# Windows:
#   - PyQt6 works out of the box
#   - UVC cameras work automatically (DirectShow/MSMF)
#   - For Boson SDK: COM port driver required (included in Boson SDK)
#
# Linux (x86-64):
#   - PyQt6 via pip: pip install PyQt6
#   - Alternative: sudo apt install python3-pyqt6 (may be older version)
#   - UVC cameras use V4L2
#   - Add user to dialout group for serial: sudo usermod -a -G dialout $USER
#
# Jetson (ARM64):
#   - OpenCV comes pre-installed with CUDA support
#   - PyQt6 via pip: pip install PyQt6
#   - VPI (Vision Programming Interface) available for GPU acceleration
#

# ============================================================================
# Troubleshooting
# ============================================================================
#
# Import errors after install:
#   - Restart terminal/IDE
#   - Check Python version: python --version
#   - Verify installation: pip list | grep [package]
#
# PyQt6 issues:
#   - Windows: pip install --upgrade PyQt6
#   - Linux: pip install --upgrade PyQt6
#
# Serial port access denied:
#   - Windows: Check Device Manager for COM port
#   - Linux: sudo usermod -a -G dialout $USER (logout/login required)
#
# Camera not detected:
#   - Check camera connections
#   - Windows: Check Device Manager
#   - Linux: ls /dev/video* or v4l2-ctl --list-devices
#
# For detailed help: See README.md Troubleshooting section
