# Archive Directory

This directory contains historical documentation, logs, and deprecated code from the Thermal Inspection Fusion Tool project.

## Directory Structure

### 📋 session-summaries/
Development session summaries and progress reports documenting major milestones and achievements.

### 🔧 sdk-docs/
FLIR Boson SDK integration documentation, including radiometric implementation plans, SDK gap analysis, and runtime connection guides.

### 📝 implementation-docs/
Technical implementation guides and plans for major features including:
- Camera detection and integration
- Firefly camera support
- Parallax compensation
- Cross-platform setup
- Performance optimization

### 🐛 fix-reports/
Bug fix reports and issue resolution documentation covering:
- UI/UX fixes and enhancements
- Palette system fixes
- Fusion mode corrections
- Edge detection improvements
- MSX mode implementation

### 🎨 ui-docs/
UI/UX design documentation including:
- AGC GUI implementation
- Design principles
- Enhancement summaries
- Test results

### 📜 deprecated-code/
Historical code and documentation from the ADAS (Advanced Driver Assistance System) origins:
- Original ADAS README backup
- Transformation changelog
- Legacy test scripts
- Qt GUI refactoring documentation

### 📊 logs/
Historical runtime logs, debug outputs, test results, and error logs from development and testing.

### 🧪 test-scripts/
Archived test and debug scripts from development:
- Deprecated test files
- Utility conversion scripts
- Debug helpers
- Palette verification tools

## Organization Date
Reorganized: 2025-11-26

## Purpose
This archive preserves the development history while keeping the main project directory clean and focused on current, active code and documentation.
